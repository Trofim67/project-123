# 📖 Инструкция пользователя

## 1. Добавление студента
1. На главном экране нажмите кнопку **«Студенты»**.
2. Введите фамилию, имя и группу (например, ИС-21).
3. Нажмите **«Добавить студента»**. Студент появится в списке ниже.
4. Для удаления нажмите кнопку **«Удалить»** напротив нужного студента и подтвердите действие.

## 2. Отметка посещаемости
1. На главном экране выберите **«Отметить посещаемость»**.
2. Введите название дисциплины и дату в формате `ГГГГ-ММ-ДД` (например, `2024-05-20`).
3. Если нужно отфильтровать студентов, введите группу (или оставьте пустым для всех).
4. Нажмите **«Загрузить студентов»**.
5. Для каждого студента выберите один из статусов: *Присутствовал*, *Отсутствовал* или *Опоздал*.
6. Нажмите **«Сохранить отметки»**.

## 3. Просмотр статистики
1. На главном экране нажмите **«Статистика»**.
2. Вы увидите общее количество отметок, а также разбивку по статусам.
3. Ниже отображается история всех отметок с датами и дисциплинами.

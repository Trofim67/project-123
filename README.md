# Система контроля посещаемости студентов

Учебное Android-приложение на Kotlin для преподавателя/куратора: ведение списка учебных групп и студентов, создание занятий, отметка посещаемости (присутствовал / отсутствовал / опоздал), просмотр истории и простая статистика. Приложение работает **локально на одном устройстве**, данные хранятся в базе Room (SQLite).

Проект разработан по плану командной работы из шести спринтов (3 участника с ротацией ролей Product Owner / Lead Developer / QA-DevOps).

## Назначение

- Вести список студентов и учебных групп.
- Создавать занятие (дисциплина/тема и дата).
- Отмечать для каждого студента статус: **Присутствовал**, **Отсутствовал**, **Опоздал**.
- Просматривать историю посещаемости с фильтром по группе.
- Получать простую статистику: количество занятий и количество отметок по каждому статусу.
- Хранить данные локально — они не пропадают после перезапуска приложения.

| Главное меню | Переход к студентам, отметке посещаемости и статистике |

## Технологии

- **Kotlin** — язык программирования.
- **Android Studio** — среда разработки.
- **XML + Activity** — классический View-based интерфейс.
- **Room / SQLite** — локальное хранение данных.
- **RecyclerView** — списки студентов, отметок и истории.
- **Coroutines** — выполнение операций с базой вне основного потока.
- **JUnit** — юнит-тесты логики валидации и статусов.
- **Git / GitHub** — контроль версий и командная работа.

## Требования

- JDK 17.
- Android SDK Platform 34.
- Минимальная версия Android: **7.0 (API 24)**. Целевая: **34**.

## Как открыть и запустить

1. Склонируйте репозиторий или распакуйте архив:
   ```bash
   git clone https://github.com/<ваш_логин>/<ваш_репозиторий>.git
   ```
2. Откройте папку проекта в Android Studio: **File → Open →** выберите `AttendanceControl`.
3. Дождитесь завершения синхронизации Gradle (первый запуск скачивает зависимости).
4. Создайте эмулятор (API 24+) или подключите устройство.
5. Нажмите **Run** ▶.

### Примечание про обёртку Gradle

Файл `gradle/wrapper/gradle-wrapper.jar` — бинарный и **не хранится в исходном репозитории**. Он создаётся автоматически:

- при открытии проекта в Android Studio, либо
- командой, если у вас установлен Gradle:
  ```bash
  gradle wrapper --gradle-version 8.4
  ```

После этого `./gradlew` и `gradlew.bat` будут работать из командной строки.

### Сборка и тесты из командной строки

```bash
# Сборка отладочной версии
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug

# Запуск юнит-тестов
./gradlew testDebugUnitTest      # Windows: gradlew.bat testDebugUnitTest
```

## Описание экранов

1. **Главное меню** — три кнопки для перехода к разделам.
2. **Студенты** — кнопка «Добавить студента» открывает диалог с полями «Имя», «Фамилия», «Учебная группа». Поля проверяются: имя и фамилия — только буквы, группа — буквы/цифры. Удаление — по кнопке с подтверждением.
3. **Отметка посещаемости** — введите дисциплину, дату и (необязательно) группу, нажмите «Начать отметку». Для каждого студента выберите статус и нажмите «Сохранить отметки».
4. **Статистика** — счётчики «Занятий», «Присутствовал», «Отсутствовал», «Опоздал» и история с фильтром по группе.

## Ограничения

- Приложение рассчитано на **одно устройство и одного преподавателя** — синхронизация и многопользовательский режим не реализованы.
- Дата вводится как свободный текст (формат ДД.ММ.ГГГГ); календарь не подключён.
- Реальные персональные данные студентов в репозитории не хранятся — для демонстрации используются вымышленные сведения.

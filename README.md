# 📱 AttendanceControl — Система контроля посещаемости

Мобильное Android-приложение на языке Kotlin для преподавателей и кураторов, позволяющее вести учет посещаемости студентов колледжа. 

## 🎯 Основные возможности
*   Ведение списка учебных групп и студентов (добавление, удаление).
*   Создание занятий с указанием дисциплины и даты.
*   Отметка статуса посещаемости (Присутствовал / Отсутствовал / Опоздал).
*   Просмотр истории и подсчет простой статистики (количество пропусков).
*   Локальное сохранение данных (Room / SQLite).

## 🛠 Технологический стек
*   **Язык:** Kotlin
*   **Среда:** Android Studio
*   **UI:** XML + Activity (View-based)
*   **База данных:** Room (SQLite)
*   **Архитектура:** MVVM (Model-View-ViewModel)
*   **Тестирование:** JUnit, ручные тест-кейсы
*   **Контроль версий:** Git

## 🚀 Как запустить проект
1. Склонируйте репозиторий: `git clone <ссылка_на_репозиторий>`
2. Откройте проект в **Android Studio**.
3. Дождитесь окончания синхронизации Gradle.
4. Запустите приложение на эмуляторе (API 24+) или реальном устройстве, нажав **Run 'app'**.

## 📁 Структура проекта
*   `data/` — Сущности Room (Entity), интерфейсы DAO и база данных (AppDatabase).
*   `ui/` — Экраны приложения (Activities) и адаптеры для списков (RecyclerView).
*   `res/layout/` — XML-файлы разметки экранов.

## ⚠️ Ограничения
Приложение работает локально на одном устройстве. Облачная синхронизация и многопользовательский режим не предусмотрены.

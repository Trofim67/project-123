# Индивидуальные отчёты участников

> Замените «Участник А/Б/В» на реальные ФИО и укажите фактические коммиты перед сдачей.

Роли распределялись по таблице ротации: каждый участник дважды выполнял каждую роль за шесть спринтов.

## Участник А

### Роли по дням

| Спринт | Роль |
| --- | --- |
| 1 | Product Owner |
| 2 | Lead Developer |
| 3 | QA/DevOps |
| 4 | Product Owner |
| 5 | Lead Developer |
| 6 | QA/DevOps |

### Личный вклад

- **Product Owner (спринты 1, 4):** сформулировал пользовательские истории и критерии приёмки; согласовал сущности данных и поведение первого запуска; сверял результат с историями.
- **Lead Developer (спринты 2, 5):** реализовал экран студентов и экран статистики; подключал `StudentDao`/`AttendanceDao`; устранял ошибки интеграции.
- **QA/DevOps (спринты 3, 6):** готовил тест-кейсы на отметку посещаемости; выполнил финальный прогон на чистом эмуляторе; оформил отчёт о проверках.

### Коммиты

- `feat: главный экран и навигация`
- `feat: экран списка студентов с валидацией`
- `feat: статистика и история с фильтром по группе`
- `docs: README и журнал спринтов`

### Приобретённые навыки

- Написание User Stories и критериев приёмки.
- Работа с RecyclerView и адаптерами.
- Составление и выполнение тест-кейсов.

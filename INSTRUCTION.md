# Инструкция пользователя

Приложение «Контроль посещаемости» предназначено для преподавателя/куратора и хранит все данные локально на устройстве.

## 1. Запуск

После установки откройте приложение. Вы увидите главный экран с тремя кнопками:

- **Студенты** — управление списком студентов.
- **Отметить посещаемость** — создание занятия и отметка статусов.
- **Статистика** — итоги и история посещаемости.

## 2. Добавление студента

1. Откройте раздел **«Студенты»**.
2. Нажмите **«Добавить студента»**.
3. Введите **Имя**, **Фамилию** и **Учебную группу** (например, «ИС-21»).
4. Нажмите **«Сохранить»**.

Приложение не примет пустые поля, а имя и фамилия должны содержать только буквы.

## 3. Удаление студента

1. В списке студентов нажмите значок удаления справа от нужной записи.
2. Подтвердите удаление в появившемся окне.

> Вместе со студентом удаляются и его отметки посещаемости.

## 4. Отметка посещаемости

1. Откройте раздел **«Отметить посещаемость»**.
2. Введите **Дисциплину/тему** (например, «Математика»).
3. Введите **Дату** в формате `ДД.ММ.ГГГГ` (например, `19.11.2026`).
4. (Необязательно) введите **Группу**, чтобы отметить только одну группу. Если оставить поле пустым, отобразятся все студенты.
5. Нажмите **«Начать отметку»**.
6. Для каждого студента выберите статус:
   - **Присутствовал**;
   - **Отсутствовал**;
   - **Опоздал**.
7. Нажмите **«Сохранить отметки»**.

Статус можно изменить до нажатия «Сохранить отметки».

## 5. Просмотр статистики

1. Откройте раздел **«Статистика»**.
2. Вверху отображаются итоги:
   - **Занятий** — количество уникальных занятий;
   - **Присутствовал / Отсутствовал / Опоздал** — количество отметок по каждому статусу.
3. Чтобы посмотреть историю по конкретной группе, введите название группы и нажмите **«Показать историю»** (пустое поле — все студенты).

История показывает: фамилию и имя студента, дисциплину, дату и статус.

## 6. Советы

- Данные сохраняются автоматически и не пропадают после перезапуска приложения.
- Для демонстрации используйте вымышленные сведения о студентах.
